# Smart Daily Planner (CLI Version)

A simple Python-based daily planner to manage tasks from the command line. This is the foundation for a future GUI version and other personal productivity tools.
The name follows some personal values. The "D", "E" and "P" are from the phonic alphabet "Delta" "Echo" and "Papa" which mean "Determination", "Excellence" and "Prepared".
This small project is to help me keep true to these values on my long journey to success.
Feel free to use this if you can find a use and stay strong... It's tough out there days. Just keep your head up and always remember:

F O R W A R D

## Features
- Add, view, and complete tasks
- Persistent storage with JSON
- Easy-to-expand modular code

## Planned features
- Weather info
- removing and archiving tasks
- GUI for a smart mirror I hope to build
